# Claude Sample

A simple responsive web app built from a [Figma design](https://www.figma.com/design/XM2mgkC07V5g470T6FGytx/Claude-Sample).

## Overview

A single-page app displaying a large "Hello, World!" headline in Inter, faithfully translated from the Figma design and made responsive for all screen sizes.

## Running

Open `index.html` directly in a browser — no build step or dependencies required.

Or serve it locally:

```bash
npx serve .
```

## Design

- **Font:** Inter Regular
- **Layout:** Fluid scaling via `clamp()` and flexbox
- **Source:** [Figma — Claude Sample](https://www.figma.com/design/XM2mgkC07V5g470T6FGytx/Claude-Sample)
